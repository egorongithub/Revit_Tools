# Sminex BIM Tools

Плагин для Autodesk Revit **2022** и **2024**. Добавляет на ленту вкладку
**«Sminex BIM Tools»** с инструментами быстрого суммирования параметров
по выделенным элементам.

## Кнопки

| Кнопка | Что делает |
|---|---|
| **Объем** | Сумма значений параметра «Объем» выделенных элементов, результат в м³ |
| **Площадь** | Сумма значений параметра «Площадь» выделенных элементов, результат в м² |
| **Длина** | Сумма значений параметра «Длина» выделенных элементов, результат в м (и мм) |
| **Количество** | Сумма значений параметра «Количество»; элементы без параметра считаются за 1 шт |
| **Сводка** | Все четыре суммы по выделению одним окном |
| **Настройки** | Правила поиска параметров, порядок источников, анализ модели |

Как это работает:

- Если элементы уже выделены — команда сразу считает сумму по ним.
  Если ничего не выделено — Revit предложит выбрать элементы.
- Для каждой проверки в **Настройках** задается список правил: имя параметра
  и источник («Авто», «Экземпляр», «Тип»). Правила проверяются по порядку —
  используется первый найденный параметр со значением.
- Источники обходятся по настраиваемому **порядку поиска** (по умолчанию:
  тип → экземпляр → системные параметры Revit). Правило с явным источником
  срабатывает только на своем шаге, «Авто» — на каждом.
- В Настройках доступна аналитика: кнопка **«Проверить в модели»** показывает
  по каждому правилу, найден ли параметр в проекте и подходит ли тип данных
  (✓ подходит, • без размерности, ✗ недопустимый тип, — не найден), а кнопка
  **«Выбрать из проекта…»** позволяет добавить правила из списка проектных
  и общих параметров документа.
- Значения размерных параметров (длина/площадь/объем) автоматически
  переводятся из внутренних единиц Revit в м / м² / м³ независимо от единиц
  проекта. Значения безразмерных параметров (число, целое, текст) берутся
  как есть, и в результатах выводится предупреждение — единицы там на
  совести автора модели.
- Округление совпадает с Revit: последняя цифра округляется вверх
  (0,8325 → 0,833). Отключается галочкой в Настройках.
- В окне результата — итоговая сумма, число учтенных и пропущенных элементов,
  а в развернутой части: разбивка по категориям и по параметрам-источникам
  (обе отключаются в Настройках) и список пропущенных элементов.

Настройки сохраняются в `%AppData%\Sminex\SminexBimTools\Settings.xml`.

## Структура репозитория

```
SminexBimTools.sln              — решение Visual Studio
src/SminexBimTools/             — исходный код плагина
  App.cs                        — точка входа, создание ленты
  Commands/                     — команды кнопок
  Core/                         — поиск параметров, суммирование, вывод результата
  Settings/                     — модель и хранение настроек
  UI/                           — WPF-окно настроек
  Resources/Icons/              — иконки ленты
addin/SminexBimTools.addin      — манифест надстройки Revit
scripts/install.ps1             — сборка и установка одним скриптом
```

## Сборка

Требуется Windows и [.NET SDK](https://dotnet.microsoft.com/download) 6.0+
(или Visual Studio 2022). Revit API подключается из NuGet-пакетов
`Nice3point.Revit.Api.*`, поэтому установленный Revit для сборки не нужен.

```powershell
dotnet build -c "Release R2022"   # для Revit 2022
dotnet build -c "Release R2024"   # для Revit 2024
```

Версия Revit выбирается конфигурацией сборки (`Debug|Release R2022|R2024`).

## Установка

### Скриптом (рекомендуется)

```powershell
cd scripts
.\install.ps1                     # Revit 2022 и 2024
.\install.ps1 -RevitVersions 2024 # только Revit 2024
```

### Вручную

Для каждой версии Revit скопируйте в `%AppData%\Autodesk\Revit\Addins\<версия>\`:

1. `addin\SminexBimTools.addin` — в корень папки;
2. `src\SminexBimTools\bin\Release R<версия>\SminexBimTools.dll` —
   в подпапку `SminexBimTools\`.

После запуска Revit на ленте появится вкладка **Sminex BIM Tools**.
При первом запуске подтвердите загрузку надстройки кнопкой
«Всегда загружать» (Always Load).

## CI

GitHub Actions собирает плагин для обеих версий Revit на каждый push;
готовые DLL можно скачать из артефактов сборки.
