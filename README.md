# Sminex BIM Tools

Плагин для Autodesk Revit **2020**, **2021**, **2022** и **2024**. Добавляет на ленту вкладку
**«Sminex BIM Tools»** с инструментами быстрого суммирования параметров
по выделенным элементам.

## Кнопки

| Кнопка | Что делает |
|---|---|
| **Объем** | Сумма значений параметра «Объем» выделенных элементов, результат в м³ |
| **Площадь** | Сумма значений параметра «Площадь» выделенных элементов, результат в м² |
| **Длина** | Сумма значений параметра «Длина» выделенных элементов, результат в м (и мм) |
| **Масса** | Сумма масс выделенных элементов (по умолчанию из SMNX_Масса экземпляра), результат в кг |
| **Количество** | Число выделенных элементов с разбивкой по категориям |
| **Сводка** | Все показатели по выделению одним окном |
| **Настройки** | Правила поиска параметров, порядок источников, анализ модели |

Как это работает:

- Если элементы уже выделены — команда сразу считает сумму по ним.
  Если ничего не выделено — Revit предложит выбрать элементы.
- Для проверок «Объем», «Площадь», «Длина» и «Масса» в **Настройках**
  задается список правил: имя параметра и источник («Авто», «Экземпляр»,
  «Тип»). Правила проверяются по порядку — используется первый найденный
  параметр со значением. «Количество» параметров не читает — это простой
  счетчик выделенных элементов.
- На каждой вкладке две таблицы: **общие правила** (для всех категорий)
  и **исключения по категориям**. Если для категории элемента заданы
  исключения, используются только они: строки общих правил к таким
  элементам не применяются, а элемент без значения попадает
  в «пропущенные». Правила исключений проверяются строго сверху
  вниз; на одну категорию можно задать несколько параметров, у каждого —
  свой источник (Экземпляр/Тип/Авто). Вид параметра значения не имеет —
  ищется любой параметр с указанным именем (системный, общий, проекта или
  семейства). Из коробки так настроена «Площадь» для категорий
  «Соединительные детали воздуховодов» и «Материалы изоляции воздуховодов»:
  всегда из SMNX_Площадь экземпляра, системная площадь не используется.
- Источники обходятся по настраиваемому **порядку поиска** (по умолчанию:
  экземпляр → тип). Правило с явным источником срабатывает только на своем
  шаге, «Авто» — на каждом. Скрытого «системного» шага нет: системные
  параметры Revit читаются как обычные, по имени — строка «Длина» находит
  системную длину элемента (в результатах такой источник подписывается
  «системный»); не нужен системный — не вписывайте его имя в правила.
- У каждого правила можно задать **размерность** для безразмерных значений:
  если параметр оказался числом или текстом, значение трактуется в выбранной
  единице (например, мм) и переводится в м/м²/м³. «Авто» — берется как есть.
- В Настройках доступна аналитика: кнопка **«Проверить в модели»** показывает
  по каждому правилу, найден ли параметр в проекте и подходит ли тип данных
  (✓ подходит, • без размерности, ✗ недопустимый тип, — не найден), а кнопка
  **«Выбрать из проекта…»** позволяет добавить правила из списка проектных
  и общих параметров документа.
- Значения размерных параметров автоматически переводятся из внутренних
  единиц Revit в м / м² / м³ / кг независимо от единиц проекта — включая
  специальные виды данных: «Размер воздуховода», «Размер трубы», толщины
  изоляции и т.п. (измерение определяется по допустимым единицам типа
  данных). Значения безразмерных параметров (число, целое, текст) берутся
  как есть, и в результатах выводится предупреждение — единицы там на
  совести автора модели.
- Округление совпадает с Revit: последняя цифра округляется вверх
  (0,8325 → 0,833). Отключается галочкой в Настройках.
- В окне результата — итоговая сумма, число учтенных и пропущенных элементов,
  а в развернутой части: разбивка по категориям и по параметрам-источникам
  (обе отключаются в Настройках) и список пропущенных элементов.
- Кнопка **«Выбрать элементы в модели…»** в окне результата позволяет
  выделить элементы по группам: по категориям, по параметрам-источникам
  (например, только те, что посчитаны из альтернативного параметра)
  или пропущенные.

Настройки сохраняются в `%AppData%\Sminex\SminexBimTools\Settings.xml`.

## Структура репозитория

```
SminexBimTools.sln              — решение Visual Studio
src/SminexBimTools/             — исходный код плагина
  App.cs                        — точка входа, создание ленты
  Commands/                     — команды кнопок
  Core/                         — поиск параметров, суммирование, вывод результата
  Settings/                     — модель и хранение настроек
  UI/                           — WPF-окно настроек
  Resources/Icons/              — иконки ленты
addin/SminexBimTools.addin      — манифест надстройки Revit
scripts/install.ps1             — сборка и установка одним скриптом
```

## Сборка

Требуется Windows и [.NET SDK](https://dotnet.microsoft.com/download) 6.0+
(или Visual Studio 2022). Revit API подключается из NuGet-пакетов
`Nice3point.Revit.Api.*`, поэтому установленный Revit для сборки не нужен.

```powershell
dotnet build -c "Release R2020"   # для Revit 2020
dotnet build -c "Release R2021"   # для Revit 2021
dotnet build -c "Release R2022"   # для Revit 2022
dotnet build -c "Release R2024"   # для Revit 2024
```

Версия Revit выбирается конфигурацией сборки
(`Debug|Release R2020|R2021|R2022|R2024`). Для Revit 2020 сборка целится
в .NET Framework 4.7.2, для остальных версий — в 4.8; в Revit 2020/2021
вместо ForgeTypeId-API используются классические `ParameterType`
и `DisplayUnitType` (условная компиляция).

## Установка

### Скриптом (рекомендуется)

```powershell
cd scripts
.\install.ps1                          # все поддерживаемые версии (2020, 2021, 2022, 2024)
.\install.ps1 -RevitVersions 2024      # только Revit 2024
.\install.ps1 -RevitVersions 2020,2021 # только Revit 2020 и 2021
```

### Вручную

Для каждой версии Revit скопируйте в `%AppData%\Autodesk\Revit\Addins\<версия>\`:

1. `addin\SminexBimTools.addin` — в корень папки;
2. `src\SminexBimTools\bin\Release R<версия>\SminexBimTools.dll` —
   в подпапку `SminexBimTools\`.

После запуска Revit на ленте появится вкладка **Sminex BIM Tools**.
При первом запуске подтвердите загрузку надстройки кнопкой
«Всегда загружать» (Always Load).

## CI

GitHub Actions собирает плагин для всех поддерживаемых версий Revit
(2020, 2021, 2022, 2024) на каждый push; готовые DLL можно скачать
из артефактов сборки.
